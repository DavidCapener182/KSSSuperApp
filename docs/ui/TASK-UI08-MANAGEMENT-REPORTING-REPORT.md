## UI delivered

The existing 23B guarded Overview read is presented with separate Required, Allocated, Accepted and Remaining measures. Each measure link moves to the paginated contributing source lines, retains all four values per line, and states which measure is being inspected in text. Exact typed source, source UUID, parent UUID, date, state and definition version remain visible. Period demand remains separate from the current operational estate. Filter disclosure shows its applied count and provides Clear filters. Loading hides the old snapshot; empty rows, invalid range, incomplete source coverage and historical-unavailable each have distinct wording. The local 390px layout stacks cards and rows. Browser testing found the definition-version disclosure was 26px high; a single local CSS correction raised it to 44px. No further product feature was added.
