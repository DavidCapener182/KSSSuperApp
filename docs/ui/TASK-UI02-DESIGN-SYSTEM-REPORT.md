## Accepted product-wide baseline

Use readable modern system sans-serif across KSS Enterprise. Avoid condensed or decorative operational fonts. Build hierarchy with size, weight, line height, spacing and restrained uppercase. Retain blue, graphite and neutral styling; no generic green success treatment. State must be legible through text or icon as well as colour. Preserve practical 44px mobile targets, visible focus, keyboard skip-to-content, a focusable main-content target, and role-derived grouped navigation. The five current groups are Overview, Clients & delivery, Operations, People & administration, and My account; omit empty groups. Navigation visibility does not confer route authority.

Workforce, Training, CRM and Service Delivery retain their distinct workflow presentation under this common KSS visual language. UI08, UI09 and future UI work should use this baseline rather than create another base style. David's acceptance covers synthetic Development only.
